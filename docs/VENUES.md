# Saskatoon venue inventory

Generated from `backend/config/venues.json` (the editable source of truth). Each venue lists the sources that back its details. Fields that could not be verified are left blank rather than guessed. Missing coordinates are geocoded from the street address by the ingest job (OpenStreetMap Nominatim) and labelled as such.

This is a **starting inventory, not a complete one**. It covers the venues that appear in the monitored sources plus well-documented music, arts and community spaces. Venues found in listings but not yet reviewed are added automatically as *provisional* and listed in the ingest report for review.

### Verification notes

- **Amigos Cantina**: Address per Discover Saskatoon (Tourism Saskatoon) Broadway guide. An older travel listing gives 632 10th St E; the venue is on the corner of 10th St & Dufferin. Official site does not print a street address on the events page.
- **Black Cat Tavern**: Address and phone from the official website and the venue's own Elfsight location list.
- **Capitol Music Club**: Website domain from Songkick venue page; address from SaskMusic directory and AllEvents. Official site could not be loaded during research, so its events page is not used as a source yet.
- **The Bassment**: Site moved to Squarespace; its JSON endpoints are disallowed by robots.txt, so events come from Songkick/Eventbrite listings.
- **Broadway Theatre**: Event list is server-rendered on the official site.
- **Louis'**: Address from the Black Cat Tavern Elfsight location list (venue-supplied); website from the same.
- **Louis' Loft**: From the Black Cat Tavern Elfsight location list.
- **Coors Event Centre**: Address and website from the Black Cat Tavern Elfsight location list.
- **Buds on Broadway**: SaskMusic directory and Discover Saskatoon (2025 nightlife guide). No official event calendar found.
- **Somewhere Else Pub & Grill**: SaskMusic directory; events seen in SaskMusic listings (2026) and Eventbrite trivia listings.
- **High Key Brewing Co.**: Address from SaskCulture event listing (June 2026); website from Bandsintown venue page.
- **Prairie Sun Brewery**: Tourism Saskatchewan lists 650 Broadway Ave. SeatGeek still shows the old 2020 Quebec Ave address (outdated, not used).
- **Shelter Brewing Company**: Discover Saskatoon brewery walking tour (2023) and Tourism Saskatchewan listing.
- **Yard & Flagon**: Hotels.com Saskatoon nightlife guide.
- **PiNK Bar and Lounge**: Hotels.com Saskatoon nightlife guide.
- **The Refinery Arts & Spirit Centre**: SaskMusic directory and multiple 2025–2026 event listings (SaskCulture, Discover Saskatoon).
- **TCU Place**: Wikipedia and Discover Saskatoon venue listing.
- **SaskTel Centre**: Discover Saskatoon gives 101-3515 Thatcher Ave; Wikipedia gives 3315 Thatcher Ave. Using the tourism listing.
- **Persephone Theatre**: Official directions page and Wikipedia.
- **Remai Modern**: Discover Saskatoon venue listing.
- **Gather Local Market**: Official website (address and hours).
- **Saskatoon Farmers' Market**: 211 Saskatchewan gives 2600 Koyl Ave; 2020 news reports gave the temporary address 2604 Koyl Ave. Current hours not verified.
- **Fox & Hounds Pub and Brewery**: Address from a single secondary listing; needs confirmation.
- **Knox United Church**: Venue named in AllEvents and Fever listings; street address not yet verified.
- **Prairieland Park**: Named in Tourism Saskatoon and AllEvents listings; address not yet verified.
